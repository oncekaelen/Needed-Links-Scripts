### Using the Microsoft Redistributable All-In-One

1. Download and extract the zip.
2. Double-click `Install-VCRedist.bat` and accept the administrator (UAC) prompt.
3. Wait for the summary. Each package is downloaded from Microsoft, checked for a valid Microsoft signature and installed silently, then the downloads are deleted.

> [!NOTE]
> Keep `Install-VCRedist.bat` and `Install-VCRedist.ps1` in the same folder.
